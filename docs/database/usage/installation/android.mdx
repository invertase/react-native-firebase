# Android Manual Installation (legacy)

> **Legacy, not supported in v26 and later.** Manual linking only applied to React Native **0.59 and earlier**. `@react-native-firebase/app` v26 declares the peer range `react-native` `>=0.60.0-0` and requires React Native's New Architecture, so those versions cannot run it. Follow [Getting Started](/) for the supported Android setup (autolinking). The steps below are kept only for projects still pinned to an older major version.

## Prerequisites

These steps assume:

- `@react-native-firebase/app` is already installed and linked (follow [Getting Started](/) for the supported setup).
- `@react-native-firebase/database` is already listed in your app `package.json` (install with `npm install --save @react-native-firebase/database` or `yarn add @react-native-firebase/database`).

Apply the four steps below **in order**, then rebuild.

## 1. Update Gradle Settings

File: `/android/settings.gradle`. Do this before editing `android/app/build.gradle`.

```groovy
// Legacy (React Native 0.59 and earlier only): not needed or supported with autolinking. See Getting Started.
// File: android/settings.gradle. Step 1 of 4 (before android/app/build.gradle dependency).
include ':@react-native-firebase_database'
project(':@react-native-firebase_database').projectDir = new File(rootProject.projectDir, './../node_modules/@react-native-firebase/database/android')
```

## 2. Update Gradle Dependencies

File: `/android/app/build.gradle`. Add the module inside the existing `dependencies { }` block after step 1.

```groovy
// Legacy (React Native 0.59 and earlier only): not needed or supported with autolinking. See Getting Started.
// File: android/app/build.gradle. Step 2 of 4 (after settings.gradle include; before MainApplication.java).
// Add this line inside the existing dependencies { } block:
implementation project(path: ":@react-native-firebase_database")
```

## 3. Add package to the Android Application

File: `/android/app/src/main/java/**/MainApplication.java` (path under `java/` matches your `applicationId` package). Register the package after steps 1 and 2. If `getPackages()` already exists on the class, add only `new ReactNativeFirebaseDatabasePackage(),` to the returned list.

```java
// Legacy (React Native 0.59 and earlier only): Java getPackages() registration, not needed or supported with autolinking.
// File: android/app/src/main/java/**/MainApplication.java. Step 3 of 4 (after Gradle settings and dependency; rebuild next).
import java.util.Arrays;
import java.util.List;

import com.facebook.react.ReactPackage;
import com.facebook.react.shell.MainReactPackage;
import io.invertase.firebase.database.ReactNativeFirebaseDatabasePackage;

@Override
protected List<ReactPackage> getPackages() {
  return Arrays.asList(
    new MainReactPackage(),
    new ReactNativeFirebaseDatabasePackage()
  );
}
```

## 4. Rebuild the project

After steps 1–3, rebuild Android from the project root:

```bash
# Legacy (React Native 0.59 and earlier only): rebuild after the manual linking steps above.
# Project root. Step 4 of 4 (after settings.gradle, app/build.gradle, and MainApplication.java).
npx react-native run-android
```
