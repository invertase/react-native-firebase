You can configure your installed modules by creating a file named `firebase.json` at the root of your project directory.
An example configuration file is available for inspection in our internal test app: [`<repo>/tests/firebase.json`](https://github.com/invertase/react-native-firebase/blob/main/tests/firebase.json)

All settings live under the top-level `react-native` key:

```json
// <project-root>/firebase.json
{
  "react-native": {
    "...": "..."
  }
}
```

## JSON Schema

Add the [Config Schema](https://github.com/invertase/react-native-firebase/blob/main/packages/app/firebase-schema.json) to your `firebase.json` file to use the Editor Intellisense

```json
{
  "$schema": "./node_modules/@react-native-firebase/app/firebase-schema.json"
}
```

## Schema Reference

The table below mirrors the descriptions in [`firebase-schema.json`](https://github.com/invertase/react-native-firebase/blob/main/packages/app/firebase-schema.json); when the schema changes, update it first and keep this table in sync.

Every property below is optional. Values are read when the app is built or launched; a property can only be changed later in JavaScript where its description says so.

### Analytics

| Property                                                | Type      | Description                                                                                                                                                                         |
| ------------------------------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `analytics_auto_collection_enabled`                     | `boolean` | Disable or enable auto collection of analytics data. Useful for opt-in-first data flows (e.g. GDPR compliance). Can be overridden in JavaScript.                                    |
| `analytics_collection_deactivated`                      | `boolean` | Permanently deactivate Analytics collection in a version of your app. Cannot be altered at runtime once set.                                                                        |
| `analytics_idfv_collection_enabled`                     | `boolean` | Disable collection of the IDFV (Identifier for Vendor) on iOS. Cannot be altered at runtime once set.                                                                               |
| `google_analytics_adid_collection_enabled`              | `boolean` | Disable collection of the Advertising ID on Android. Cannot be altered at runtime once set. See [Disable Ad Id usage on Android](/analytics/usage#disable-ad-id-usage-on-android).  |
| `google_analytics_ssaid_collection_enabled`             | `boolean` | Disable collection of SSAID (`Settings.Secure.ANDROID_ID`) on Android. Cannot be altered at runtime once set.                                                                       |
| `google_analytics_automatic_screen_reporting_enabled`   | `boolean` | Disable automatic screenview reporting. Cannot be altered at runtime once set.                                                                                                      |
| `google_analytics_registration_with_ad_network_enabled` | `boolean` | On iOS the SDK automatically registers your app with Apple for ad network attribution via SKAdNetwork. Defaults to `true`; set to `false` to disable.                               |
| `analytics_default_allow_analytics_storage`             | `boolean` | Default consent for storage (such as app identifiers) related to analytics, e.g. visit duration.                                                                                    |
| `analytics_default_allow_ad_storage`                    | `boolean` | Default consent for storage (such as device identifiers) related to advertising.                                                                                                    |
| `analytics_default_allow_ad_user_data`                  | `boolean` | Default consent for sending user data to Google for advertising purposes.                                                                                                           |
| `analytics_default_allow_ad_personalization_signals`    | `boolean` | Whether a user's Analytics data may be used for personalized advertising in other products. May be overridden at runtime via `setUserProperty` on the `allow_personalized_ads` key. |

### App

| Property                              | Type                                                      | Description                                                                                                                                                                                                                                                                               |
| ------------------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app_data_collection_default_enabled` | `boolean`                                                 | Whether automatic data collection is enabled for all products, unless overridden by product-specific settings. Set to `false` for opt-in-first data flows (e.g. GDPR). May be overridden dynamically in JavaScript via the `automaticDataCollectionEnabled` `FirebaseAppConfig` property. |
| `app_log_level`                       | `string` (`"error"` \| `"warn"` \| `"info"` \| `"debug"`) | Sets the log level across all modules (iOS only). Logs messages at the configured level or lower. Note: an app running from the App Store never logs above `info`, even at a more verbose setting.                                                                                        |
| `app_check_token_auto_refresh`        | `boolean`                                                 | If disabled, App Check will not periodically auto-refresh the app check token. Useful for opt-in-first data flows. Defaults to the SDK-wide data collection setting if unset. May be overridden dynamically in JavaScript.                                                                |

### Crashlytics

| Property                                                    | Type      | Description                                                                                                                                                                                                                     |
| ----------------------------------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `crashlytics_auto_collection_enabled`                       | `boolean` | Whether Crashlytics sends out any reports. If you want users to opt-in, disable this here and enable it later at runtime once they opt-in.                                                                                      |
| `crashlytics_debug_enabled`                                 | `boolean` | Crashlytics is disabled by default in debug mode (stack traces are already available while debugging). Set to `true` to enable it regardless of debug mode, e.g. to test your integration (reports are sent on next app start). |
| `crashlytics_is_error_generation_on_js_crash_enabled`       | `boolean` | By default, a global JavaScript-level unhandled exception handler logs unhandled JS exceptions as fatal crashes (non-fatal prior to v11.3.0) with JS stacks. Set to `false` to disable JS-level crash handling.                 |
| `crashlytics_javascript_exception_handler_chaining_enabled` | `boolean` | By default, existing global JS-level unhandled exception handlers are preserved: Crashlytics reports then passes the exception on for further handling. Set to `false` to stop error handling after logging the JS-level crash. |
| `crashlytics_ndk_enabled`                                   | `boolean` | Crashlytics NDK reporting is enabled by default, capturing crashes originating from the Yoga layout engine used by React Native. Set to `false` to disable.                                                                     |

### In-App Messaging

| Property                                   | Type      | Description                                                                                                                                                 |
| ------------------------------------------ | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `in_app_messaging_auto_collection_enabled` | `boolean` | Enable or disable automatic data collection for Firebase In-App Messaging. Useful for opt-in-first data flows (e.g. GDPR). Can be overridden in JavaScript. |

### Cloud Messaging

| Property                                                         | Type      | Description                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------------------------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `messaging_auto_init_enabled`                                    | `boolean` | Firebase generates an Instance ID, used by FCM to generate a registration token and by Analytics for data collection. Set to `false` to prevent Instance ID auto-generation (disables auto initialization for FCM and Analytics).                                                                                                                                                                              |
| `messaging_installation_id_enabled`                              | `boolean` | Opt in to Firebase Installation ID (FID) messaging APIs (`register` / `unregister` / `onRegistered` / `onUnregistered`). Off by default. When enabled, the FCM token APIs (`getToken` / `deleteToken` / `onTokenRefresh`) are disabled (mutually exclusive). Maps to the Android meta-data `firebase_messaging_installation_id_enabled` and the iOS `Info.plist` key `FirebaseMessagingInstallationIdEnabled`. |
| `messaging_android_headless_task_timeout`                        | `number`  | Milliseconds a background event sent to `setBackgroundMessageHandler` has to resolve before it is automatically canceled to free up device resources. Defaults to `60000` (60 seconds).                                                                                                                                                                                                                        |
| `messaging_android_notification_delegation_enabled`              | `boolean` | On Android Q+ with a current Play Services version, FCM may be delegated, disabling Firebase message listeners. Disabled by default; re-enable if necessary.                                                                                                                                                                                                                                                   |
| `messaging_android_notification_channel_id`                      | `string`  | Android notifications use a default Notification Channel (`Miscellaneous`, created by FCM). Set this to change which channel is used.                                                                                                                                                                                                                                                                          |
| `messaging_android_notification_delivery_metrics_export_enabled` | `boolean` | Whether FCM exports message delivery metrics to BigQuery. Defaults to disabled.                                                                                                                                                                                                                                                                                                                                |
| `messaging_android_notification_color`                           | `string`  | Android color resource name used to tint notification content (such as the small icon, title, etc). The library provides a set of predefined colors corresponding to the HTML colors for convenience.                                                                                                                                                                                                          |
| `messaging_ios_auto_register_for_remote_messages`                | `boolean` | Whether `registerForRemoteNotifications` is called automatically on app launch (recommended). Defaults to `true`. If `false`, call `registerDeviceForRemoteMessages(getMessaging())` early in app startup, otherwise you will not receive remote messages/notifications.                                                                                                                                       |
| `messaging_ios_foreground_presentation_options`                  | `array`   | On iOS, how to present a notification while the app is in the foreground.                                                                                                                                                                                                                                                                                                                                      |
| `messaging_max_stored_notifications`                             | `number`  | How many notifications are retained on-device for background storage. Values `<= 0` disable storage and clear previously retained notifications. Priority order: SharedPreferences -> `firebase.json` -> AndroidManifest. Default `100`. Very small values may cause excessive deletions; large values/content risk `OutOfMemoryError`s.                                                                       |

| Property                       | Type      | Description                                                                                                                                        |

### Android Internals

| Property                                   | Type      | Description                                                                                                                                                                                                             |
| ------------------------------------------ | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `android_task_executor_maximum_pool_size`  | `number`  | Maximum pool size of the `ThreadPoolExecutor` used by React Native Firebase on Android. Defaults to `1`. Larger values typically improve performance when running large numbers of async tasks, e.g. Firestore queries. |
| `android_task_executor_keep_alive_seconds` | `number`  | Keep-alive time, in seconds, of the `ThreadPoolExecutor` used by React Native Firebase on Android. Defaults to `3`. Excess threads idle longer than this are terminated.                                                |
| `android_background_activity_names`        | `array`   | Names (as returned by `getShortClassName()`) of Activities used outside the context of React Native. Ignored when determining whether the app is in the foreground for calling JavaScript background handlers.          |
| `android_bypass_emulator_url_remap`        | `boolean` | On Android, Firebase emulator URLs are remapped from `localhost` to `10.0.2.2`. Set to `true` if you don't need this behavior.                                                                                          |
