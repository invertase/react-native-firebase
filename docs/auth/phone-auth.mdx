## Prerequisites

- `@react-native-firebase/app` and `@react-native-firebase/auth` installed and native config completed per [Authentication usage](/auth/usage) / [Getting Started](/). From v26, New Architecture is required for packages with a native bridge.
- **Phone** sign-in provider enabled on the [Firebase Console](https://console.firebase.google.com/project/_/authentication/providers).
- Platform app verification completed (reCAPTCHA / APNs / Play Integrity) per the sections below. Firebase Phone Auth is not available in every country; see Firebase [FAQs](https://firebase.google.com/support/faq/#develop).

Phone authentication lets users sign in with an SMS code. Phone numbers that end users provide for authentication are sent and stored by Google to improve spam and abuse prevention across Google services, including Firebase. Obtain appropriate end-user consent before using phone number sign-in.

# iOS Setup

Complete steps 1 and 2 from the [Firebase iOS phone auth docs](https://firebase.google.com/docs/auth/ios/phone-auth#enable-phone-number-sign-in-for-your-firebase-project). Re-download `GoogleService-Info.plist` when instructed, and add your custom URL scheme to the project plist so the reCAPTCHA flow can return to the app.

Phone auth requires app verification. Automatic verification uses data-only Firebase Cloud Messaging. Data-only FCM needs a physical device with background refresh enabled. On Simulator, or when background refresh is disabled, Auth falls back to reCAPTCHA — use that path to confirm reCAPTCHA is configured.

For automated testing you can disable app verification via [`AuthSettings.appVerificationDisabledForTesting`](https://reference.rnfirebase.io/_react-native-firebase/auth/FirebaseAuthTypes/AuthSettings.html#appVerificationDisabledForTesting) before any phone auth methods.

# Android Setup

Complete steps 1 and 2 from the [Firebase Android phone auth docs](https://firebase.google.com/docs/auth/android/phone-auth#enable-phone-number-sign-in-for-your-firebase-project).

To force reCAPTCHA instead of Play Integrity during manual testing, set [`appVerificationDisabledForTesting`](https://reference.rnfirebase.io/_react-native-firebase/auth/FirebaseAuthTypes/AuthSettings.html#appVerificationDisabledForTesting) before [`verifyPhoneNumber`](https://reference.rnfirebase.io/_react-native-firebase/auth/verifyPhoneNumber.html).

# Expo Setup

Phone auth needs the `@react-native-firebase/auth` config plugin (in addition to `@react-native-firebase/app`). That plugin is required for phone auth; it is not required for every Auth provider. It [sets up reCAPTCHA](https://firebase.google.com/docs/auth/ios/phone-auth#set-up-recaptcha-verification) on iOS.

File: `app.json` (or `app.config.js`). Add the plugins, then create a [development build](https://docs.expo.dev/develop/development-builds/introduction/#use-libraries-with-native-code-that-arent) (Expo Go cannot host this native config). See [Expo install](/#installation-for-expo-projects).

```json
{
  "expo": {
    "plugins": ["@react-native-firebase/app", "@react-native-firebase/auth"]
  }
}
```

# Sign-in

`signInWithPhoneNumber` accepts a phone number, sends an SMS code, and returns a confirmation object. Call `confirm(code)` with the SMS code.

```jsx
import React, { useState, useEffect } from 'react';
import { Button, TextInput } from 'react-native';
import { getAuth, onAuthStateChanged, signInWithPhoneNumber } from '@react-native-firebase/auth';

function PhoneSignIn() {
  // If null, no SMS has been sent
  const [confirm, setConfirm] = useState(null);

  // verification code (OTP)
  const [code, setCode] = useState('');

  function handleAuthStateChanged(user) {
    if (user) {
      // Some Android devices auto-retrieve the SMS code and complete sign-in
      // without the user typing it. Hide the code UI and navigate away when
      // this fires; entering the same code again will fail because it was used.
    }
  }

  useEffect(() => {
    const subscriber = onAuthStateChanged(getAuth(), handleAuthStateChanged);
    return subscriber;
  }, []);

  async function handleSignInWithPhoneNumber(phoneNumber) {
    const confirmation = await signInWithPhoneNumber(getAuth(), phoneNumber);
    setConfirm(confirmation);
  }

  async function confirmCode() {
    try {
      await confirm.confirm(code);
    } catch (error) {
      console.log('Invalid code.');
    }
  }

  if (!confirm) {
    return (
      <Button
        title="Phone Number Sign In"
        onPress={() => handleSignInWithPhoneNumber('+1 650-555-3434')}
      />
    );
  }

  return (
    <>
      <TextInput value={code} onChangeText={text => setCode(text)} />
      <Button title="Confirm Code" onPress={() => confirmCode()} />
    </>
  );
}
```

Upon successful sign-in, any [`onAuthStateChanged`](/auth/usage#listening-to-authentication-state) listeners receive the signed-in user.

# Testing

For local test numbers, add your machine's SHA-1 debug key in the Firebase Console (see [Getting Started](/)).

In the [Firebase Console](https://console.firebase.google.com/project/_/authentication/providers), open the Phone provider → **Phone numbers for testing**. Add a number (for example `+44 7444 555666`) and a test code (for example `123456`). `signInWithPhoneNumber` with that number and code completes sign-in without sending SMS.

# MFA-like Account Creation

After creating a user with email/password, use `verifyPhoneNumber` and `linkWithCredential` to attach a phone number. That is an MFA-like account-creation flow only. Full MFA requires Identity Platform and the flows on [Multi-factor Auth](/auth/multi-factor-auth); see also [Identity Platform MFA](https://cloud.google.com/identity-platform/docs/web/mfa).

```jsx
import React, { useState, useEffect } from 'react';
import { Button, TextInput, Text } from 'react-native';
import {
  PhoneAuthProvider,
  getAuth,
  onAuthStateChanged,
  createUserWithEmailAndPassword,
  verifyPhoneNumber,
  linkWithCredential,
} from '@react-native-firebase/auth';

function PhoneVerification() {
  const [initializing, setInitializing] = useState(true);
  const [user, setUser] = useState(
    /** @type {import('@react-native-firebase/auth').User | null} */ (null),
  );
  const [confirm, setConfirm] = useState(null);
  const [code, setCode] = useState('');

  function handleAuthStateChanged(nextUser) {
    setUser(nextUser);
    if (initializing) {
      setInitializing(false);
    }
  }

  useEffect(() => {
    const subscriber = onAuthStateChanged(getAuth(), handleAuthStateChanged);
    return subscriber;
  }, []);

  async function createAccount() {
    try {
      await createUserWithEmailAndPassword(
        getAuth(),
        'jane.doe@example.com',
        'SuperSecretPassword!',
      );
      console.log('User account created & signed in!');
    } catch (error) {
      if (error.code === 'auth/email-already-in-use') {
        console.log('That email address is already in use!');
      }

      if (error.code === 'auth/invalid-email') {
        console.log('That email address is invalid!');
      }
      console.error(error);
    }
  }

  async function handlePhoneNumberVerification(phoneNumber) {
    const confirmation = await verifyPhoneNumber(getAuth(), phoneNumber);
    setConfirm(confirmation);
  }

  async function confirmCode() {
    try {
      const currentUser = getAuth().currentUser;
      if (!currentUser) {
        throw new Error('No user is signed in');
      }
      const credential = PhoneAuthProvider.credential(confirm.verificationId, code);
      const userCredential = await linkWithCredential(currentUser, credential);
      setUser(userCredential.user);
    } catch (error) {
      if (error.code === 'auth/invalid-verification-code') {
        console.log('Invalid code.');
      } else {
        console.log('Account linking error');
      }
    }
  }

  if (initializing) return null;

  if (!user) {
    return <Button title="Login" onPress={() => createAccount()} />;
  }

  if (!user.phoneNumber) {
    if (!confirm) {
      return (
        <Button
          title="Verify Phone Number"
          onPress={() => handlePhoneNumberVerification('+1 650-555-3434')}
        />
      );
    }
    return (
      <>
        <TextInput value={code} onChangeText={text => setCode(text)} />
        <Button title="Confirm Code" onPress={() => confirmCode()} />
      </>
    );
  }

  return (
    <Text>
      Welcome! {user.phoneNumber} linked with {user.email}
    </Text>
  );
}
```
