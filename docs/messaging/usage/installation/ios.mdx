# iOS Manual Installation (legacy)

> **Legacy, not supported in v26 and later.** Manual linking only applied to React Native **0.59 and earlier**. `@react-native-firebase/app` v26 declares the peer range `react-native` `>=0.60.0-0` and requires React Native's New Architecture, so those versions cannot run it. Follow [Getting Started](/) for the supported iOS setup (autolinking). The manual linking steps below are kept only for projects still pinned to an older major version. The [iOS Messaging Setup](/messaging/usage/ios-setup) (Push Notifications capability, Background Modes, APNs key) is separate and is still required, including for Expo projects: the `@react-native-firebase/messaging` config plugin only sets Android notification icon and color metadata, and does not enable these iOS capabilities or link an APNs key.

## Prerequisites

These steps assume:

- `@react-native-firebase/app` is already installed and linked (follow [Getting Started](/) for the supported setup).
- `@react-native-firebase/messaging` is already listed in your app `package.json` (install with `npm install --save @react-native-firebase/messaging` or `yarn add @react-native-firebase/messaging`).
- CocoaPods is installed and you can run `pod` from a shell.

Apply the two steps below **in order**, then rebuild.

## 1. Add the Pod

File: `/ios/Podfile`. Add the `RNFBMessaging` pod inside your app `target` block before running `pod install`.

```ruby
# Legacy (React Native 0.59 and earlier only): not needed or supported with autolinking. See Getting Started.
# File: ios/Podfile. Step 1 of 2 (before pod install). Add inside your app target block.
target 'app' do
  pod 'RNFBMessaging', :path => '../node_modules/@react-native-firebase/messaging'
end
```

Replace `'app'` with your real Xcode target name if it differs.

## 2. Update Pods and rebuild the project

From the project root, install pods then rebuild iOS. Do this only after the Podfile change in step 1.

```bash
# Legacy (React Native 0.59 and earlier only): rebuild after the manual linking step above.
# Project root. Step 2 of 2 (after ios/Podfile RNFBMessaging pod entry).
cd ios/
pod install --repo-update
cd ..
npx react-native run-ios
```

## iOS Messaging Setup (still required)

This step is not legacy, and it also applies to Expo projects because the messaging config plugin does not set up these iOS capabilities. After linking (or after autolinking), complete [iOS Messaging Setup](/messaging/usage/ios-setup) (Push Notifications capability, Background Modes, APNs key) before expecting FCM delivery on a device.
