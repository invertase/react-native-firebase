# Android Manual Installation (legacy)

> **Legacy, not supported in v26 and later.** Manual linking only applied to React Native **0.59 and earlier**. `@react-native-firebase/app` v26 declares the peer range `react-native` `>=0.60.0-0` and requires React Native's New Architecture, so those versions cannot run it. Follow [Getting Started](/) for the supported Android setup (autolinking). The manual linking steps below are kept only for projects still pinned to an older major version. The Crashlytics Gradle setup in [Android Setup](/crashlytics/android-setup) is separate and still required. For Expo projects, the `@react-native-firebase/crashlytics` config plugin covers only steps 2 and 3 of [Android Setup](/crashlytics/android-setup).

## Prerequisites

These steps assume:

- `@react-native-firebase/app` is already installed and linked (follow [Getting Started](/) for the supported setup).
- `@react-native-firebase/crashlytics` is already listed in your app `package.json` (install with `npm install --save @react-native-firebase/crashlytics` or `yarn add @react-native-firebase/crashlytics`).

Apply the three manual linking steps below **in order**, then complete the Crashlytics Gradle setup and rebuild.

## 1. Update Gradle Settings

File: `/android/settings.gradle`. Do this before editing `android/app/build.gradle`.

```groovy
// Legacy (React Native 0.59 and earlier only): not needed or supported with autolinking. See Getting Started.
// File: android/settings.gradle. Step 1 of 3 (before android/app/build.gradle dependency).
include ':@react-native-firebase_crashlytics'
project(':@react-native-firebase_crashlytics').projectDir = new File(rootProject.projectDir, './../node_modules/@react-native-firebase/crashlytics/android')
```

## 2. Update Gradle Dependencies

File: `/android/app/build.gradle`. Add the module inside the existing `dependencies { }` block after step 1.

```groovy
// Legacy (React Native 0.59 and earlier only): not needed or supported with autolinking. See Getting Started.
// File: android/app/build.gradle. Step 2 of 3 (after settings.gradle include; before MainApplication.java).
// Add this line inside the existing dependencies { } block:
implementation project(path: ":@react-native-firebase_crashlytics")
```

## 3. Add package to the Android Application

File: `/android/app/src/main/java/**/MainApplication.java` (path under `java/` matches your `applicationId` package). Register the package after steps 1 and 2. If `getPackages()` already exists on the class, add only `new ReactNativeFirebaseCrashlyticsPackage(),` to the returned list.

```java
// Legacy (React Native 0.59 and earlier only): Java getPackages() registration, not needed or supported with autolinking.
// File: android/app/src/main/java/**/MainApplication.java. Step 3 of 3 (after Gradle settings and dependency).
import java.util.Arrays;
import java.util.List;

import com.facebook.react.ReactPackage;
import com.facebook.react.shell.MainReactPackage;
import io.invertase.firebase.crashlytics.ReactNativeFirebaseCrashlyticsPackage;

@Override
protected List<ReactPackage> getPackages() {
  return Arrays.asList(
    new MainReactPackage(),
    new ReactNativeFirebaseCrashlyticsPackage()
  );
}
```

## Crashlytics Gradle setup (still required)

This step is not legacy. Every React Native CLI Android setup, including projects that use autolinking, also needs the Crashlytics Gradle plugin steps. In Expo projects the `@react-native-firebase/crashlytics` config plugin covers only steps 2 and 3 of that page (adding the Gradle plugin dependency and applying the plugin); the Google repository (step 1) and the optional NDK block (step 4) stay manual. Steps 1 and 4 need a native `android/` folder, which `npx expo prebuild` generates in an Expo project. Because that folder is regenerated by `npx expo prebuild --clean` and by EAS Build, edits made directly in it may not persist, so a workflow that regenerates it needs those changes made another way (for example a custom config plugin). Follow [Android Setup](/crashlytics/android-setup), then rebuild.

## Rebuild the project

After the steps above (the manual linking steps only if you are on React Native 0.59 or earlier, then the Crashlytics Gradle setup), rebuild Android from the project root:

```bash
# Project root. Final step, after the Crashlytics Gradle setup.
npx react-native run-android
```
